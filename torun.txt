SupplyIQ — how to run
=====================

Start everything (first run auto-seeds 2 years of data + trains models, ~1-2 min):
    docker compose up --build

Open:
    Frontend:  http://localhost:3000
    API docs:  http://localhost:8000/docs
    Health:    http://localhost:8000/api/v1/health

Stop:
    docker compose down

Stop AND wipe all data/models (next start re-seeds + re-trains):
    docker compose down -v

Skip the auto-bootstrap (after first run, for faster restarts):
    create a .env file in this folder with:  BACKEND_AUTO_BOOTSTRAP=false

Manual one-offs (stack must be running):
    Re-seed:               docker compose exec backend python /app/infra/seed.py
    Re-train models:       docker compose exec backend python /app/backend/ml/train.py
    Simulate a day of data: docker compose exec backend python -m pipeline.flows.ingestion_flow
    Run backend tests:     docker compose exec backend sh -c "cd /app && python -m unittest discover -s backend/tests"
